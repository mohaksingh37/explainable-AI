LIME — Local Explanation

LIME (Local Interpretable Model-agnostic Explanations) creates a simpler linear model around this specific prediction. Each bar shows how much a feature increased or decreased the conviction probability.

SHAP — Feature Contribution

SHAP (SHapley Additive exPlanations) measures each feature's marginal contribution by comparing the prediction with and without that feature. Positive values push towards conviction; negative values push towards acquittal.

Global Feature Importance

This shows which features are generally most important across all cases in the training dataset — not just for this specific case. Based on mean decrease in Gini impurity across all 200 decision trees.

Random Forest — Tree Voting

Random Forest is an ensemble of 200 decision trees. Each tree "votes" independently. The final prediction is a majority vote. This shows how the trees voted for this case.

What is Explainable AI?

Traditional AI models — especially ensemble methods like Random Forest — are often called "black boxes." They produce predictions but cannot easily explain why. Explainable AI (XAI) is the set of techniques that opens that black box.

🔍

LIME

Local Interpretable Model-agnostic Explanations explains individual predictions by creating a local linear approximation. It perturbs the input slightly and fits a simple model to understand which features matter most for this specific prediction.

g(z) ≈ f(x) near x g = simple model, f = complex model
📊

SHAP

SHapley Additive exPlanations uses game theory (Shapley values) to fairly distribute the "credit" for a prediction among features. It compares predictions made with and without each feature to measure its marginal contribution.

φᵢ = Σ [f(S∪{i}) − f(S)] Sum of marginal contributions over all feature subsets
🌐

Feature Importance

Global Importance (Mean Decrease Impurity) measures how much each feature reduces uncertainty (Gini impurity) across all decision trees. Higher importance = more influential feature globally.

Imp(f) = Σ nodes Δ impurity Summed across all trees & all splits on feature f
🌳

Random Forest

An ensemble of 200 Decision Trees. Each tree is trained on a random subset of data (bagging) and features (feature randomness). Final prediction is by majority vote, making it robust and accurate.

ŷ = mode{ h₁(x), h₂(x), ..., h₂₀₀(x) } Majority vote of 200 decision trees

Why Legal Domain?

Legal AI is one of the highest-stakes applications of machine learning. A wrong prediction can affect a person's freedom. This makes explainability non-negotiable — judges, lawyers, and defendants must understand why the model says what it says. This project demonstrates how XAI techniques make AI trustworthy and auditable in high-stakes domains.
